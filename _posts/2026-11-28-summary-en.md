### [Code-driven AI illustrations are more useful than images from dedicated image models](https://simonwillison.net/2026/Nov/28/code-driven-ai-illustrations/) ⭐️ 8.0/10

Frontier LLMs released in late 2026 generate visual assets by writing code \(SVG, HTML/CSS, Blender scripts\) rather than outputting bitmaps. This approach produces editable, precise results for diagrams, UI components, and game assets. The author demonstrated this by iterating on an SVG poster design with Gemini 4 Neon, correcting text placement and visual details through prompt refinement. Code-driven outputs allow direct editing of elements and layers, avoiding the glitches, inconsistent text rendering, and flat structure inherent to dedicated image models like Stable Diffusion or DALL-E.

rss · Simon Willison - Coding Agents · Nov 28, 17:45

**「Operator Takeaway」** Route tasks requiring editable diagrams, UI components, or precise visual assets to coding agents that generate SVG, HTML, or script-based outputs instead of using dedicated bitmap image models.

**「Evidence and Limits」** The workflow requires iteration because some environments \(like AI Studio\) do not render SVGs natively, preventing the model from spotting visual mistakes without assistance. Dedicated image models remain preferable for generating photorealistic images.
